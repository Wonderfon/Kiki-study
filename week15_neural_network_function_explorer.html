Forward Pass Explanation

Input ($x$): Features fed into the network. (2D).

Linear Step ($z$): For a neuron $j$ in layer $l$, it calculates the weighted sum of outputs from the previous layer plus a bias:
$z_j^{(l)} = \sum_i (w_{ij}^{(l)} \cdot a_i^{(l-1)}) + b_j^{(l)}$

Activation ($a$): A non-linear function applied to $z$.
- ReLU ($a = \max(0, z)$): Adds 'bends' or 'folds' to the surface.
- tanh ($a = \frac{e^z - e^{-z}}{e^z + e^{-z}}$): S-shaped curve between -1 and 1.

Output ($\hat{y}$): The final layer aggregates the hidden features into a single prediction.

Try adjusting a bias in the first layer to shift a 'fold', or a weight in the final layer to amplify it!
